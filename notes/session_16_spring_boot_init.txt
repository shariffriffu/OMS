SESSION 16: SPRING BOOT INITIALIZATION
===========================================
🎯 OBJECTIVE: Generate, configure, and run a Spring Boot application 
connected to a PostgreSQL database.

🔑 KEY CONCEPTS:
• Spring Initializr: The official tool to generate project skeletons.
• Maven (pom.xml): Manages dependencies (Spring Web, JPA, PostgreSQL Driver).
• application.properties: The central place for configuration (DB URL, credentials).
• Embedded Tomcat: Spring Boot includes a web server; no separate installation needed.
• HikariCP: The default, high-performance connection pool used by Spring Boot.

💻 SYNTAX CHEAT SHEET (application.properties):
spring.datasource.url=jdbc:postgresql://localhost:5432/oms_database
spring.datasource.username=postgres
spring.datasource.password=YOUR_PASSWORD
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

⚠️ COMMON MISTAKES:
• Putting application.properties in the wrong folder (must be src/main/resources).
• Forgetting to save the file before running.
• Typos in the property keys (e.g., 'ur1' instead of 'url').
