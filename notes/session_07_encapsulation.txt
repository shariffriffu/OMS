SESSION 7: OOP - ENCAPSULATION
===========================================
🎯 OBJECTIVE: Protect object data using private fields and public 
getters/setters, adding validation logic.

🔑 KEY CONCEPTS:
• Public fields are dangerous (anyone can set invalid data).
• Encapsulation = Data Hiding + Controlled Access.
• 'private': Field can only be accessed inside its own class.
• 'this' keyword: Refers to the current object instance, used to 
  distinguish between a parameter and a class field with the same name.

💻 SYNTAX CHEAT SHEET:
class Customer {
    private String email;

    public String getEmail() { return this.email; }

    public void setEmail(String email) {
        if (email.contains("@")) {
            this.email = email;
        } else {
            System.out.println("Error: Invalid email");
        }
    }
}

⚠️ COMMON MISTAKES:
• Forgetting 'this.' when parameter and field names match.
• Making the setter 'void' but forgetting to actually assign the value.
